# 🧳 pp-band-stitch-catalog

## ステッチパターン図鑑 / PP-BAND STITCH PATTERNS CATALOG (ver. 1.0)

PPバンドの後差しで構成される様々な幾何学模様を、論理的なコード体系としてハック・体系化したステッチパターン図鑑の公式リポジトリです。

---

## 📖 図鑑の概要

本書は、プラカゴ編みにおける「後差し模様（ステッチ）」のバンド配置や色の順列組み合わせを論理的な記号（ステッチコード）として定義し、その規則性と美しさをまとめた世界初の図鑑です。
縦横に差すレベル1（直線系）と斜めに差すレベル2（クロスベース）の **全図柄** を **42点の試作写真** とともに完全収録しています。

幾何学的な対称性により、まったく同じ模様であっても複数のコードが対応する数理的性質を持っています。各ページには模様を数学的に定義する「代表コード」を記載し、差し方表には実際に製作した際の「製作コード」を記載しています。

---

## 🎁 3つの大きな特徴

### 1. 完全フリーの「CC0（パブリック・ドメイン）」公開
本図鑑に収録されたステッチデータやコードは、バンドの配置や色の組み合わせによる幾何学的な構成であり、特定の創作物として独占するものではありません。
商用利用、作品への応用、改変、データの再配布、Webツールやアプリへの組み込みなど、**あらゆる創作のためのパーツ（部品）** としてどなたでも完全自由にご利用いただけます。

### 2. QRコードからWebシミュレーターへ一瞬で連動
図鑑の各ページには専用のQRコード・リンク配置されています。スキャン/タップするだけで、該当する模様の **「Web色幅シミュレーター」** へ直接ジャンプし、ご自身の好きな色やバンド幅（1/2幅、1/4幅など）でのカラー試作をリアルタイムに楽しむことができます。

### 3. AIフレンドリーな設計（機械可読性）
このPDFデータは、人間にとって読みやすいだけでなく、**将来のAIがデータを正確にパースできるようにセマンティックに構造化（AI-Readability）**　されています。
データをAIに読み込ませることで、「アヒル模様の製作コードを教えて」といった音声ガイドや、対話式のステッチ・パートナーとして活用することが可能です.
