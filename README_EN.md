# 🧳 pp-band-stitch-catalog

## PP-BAND STITCH PATTERNS CATALOG (ver. 1.0)
This is the official repository for the "PP-BAND STITCH PATTERNS CATALOG," a systematic catalog and logical coding framework for various geometric weaving patterns constructed by post-inserting PP-bands.

#### 📖 About the Catalog
This catalog is the world's first comprehensive guide that defines "post-insertion stitches" (decorative stitch patterns inserted into a woven base) in PP-band basket weaving using logical symbols ("stitch codes") to showcase their mathematical regularity and beauty. It completely archives **all geometric patterns** of Level 1 (linear/vertical-horizontal stitches) and Level 2 (cross-based diagonal stitches) along with **42 trial prototype photos** and detailed weaving formulas.

Due to geometric symmetry, a single visual pattern can correspond to multiple different mathematical configurations. Each page highlights a "Representative Code" that defines the pattern mathematically, while the instruction tables list the specific "Production Code" used for the actual photographed prototype. Whichever code you start weaving with, you will successfully achieve the exact same geometric pattern.

#### 🎁 3 Key Features
##### 1. Fully Open under "CC0 (Public Domain)"
All stitch patterns and logical codes compiled in this book are geometric configurations based on the permutation and combination of band placements and color layouts. Therefore, they are not exclusive creative properties. You are completely free to use, modify, distribute, and apply them commercially in your physical crafts, digital designs, websites, or software applications. They are designed to be the **"minimum components (parts)"** for your creative projects.

##### 2. Direct QR Code Integration with Web Simulator
Each catalog page features a dedicated QR code or link. Simply scan or tap it to instantly jump to the corresponding **"Web Color & Band-Width Simulator"**, allowing you to test custom color combinations and different band widths (e.g., 1/2 width, 1/4 width) in real-time before you begin weaving.

##### 3. AI-Friendly & Machine-Readable Design
This PDF data is not only easy for humans to read but is also **semantically structured (AI-Readability) so that future AI agents can accurately parse the data**. By uploading this catalog to your personal AI assistant, you can turn it into an interactive, voice-guided weaving partner (e.g., asking "Show me the production code for the Duck pattern").
